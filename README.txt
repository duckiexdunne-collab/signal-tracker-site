WIGHT SIGNAL — STATIC WEBSITE
=============================

UPLOAD INSTRUCTIONS
1. Unzip this archive.
2. Upload index.html, styles.css, script.js and the complete assets folder to your website's public root (e.g. public_html).
3. Open your domain. No database, build tooling, API keys, or third-party fonts are required.

For GitHub Pages / Netlify / Cloudflare Pages: deploy this folder directly as a static site. No build command is needed.

CUSTOMISATION
- Change wording/content in index.html.
- Adjust colours/fonts/layouts in styles.css.
- Replace original atmospheric concept art in assets/ with real in-game captures when ready.
- Search "LINK COMING SOON" / "COMING SOON" in index.html to replace placeholders with real Discord/Steam URLs.
- The map is deliberately labelled a CONCEPT MAP: it is decorative, not exact terrain navigation.
- The prototype/development text is qualitative; no invented percentage progress bars or release dates.

COPYRIGHT / ATTRIBUTION
Concept imagery is AI-generated for this site, not actual gameplay screenshots. The site explicitly labels the artwork as conceptual.
